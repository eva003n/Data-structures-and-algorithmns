# Quick sort(partition exvhange sort)
- This is a divide an conquer algorithm
- Select a pivot element in the array and dividing the other elements in to subarrays based on whether they are smaller than or greater than the pivot 
- The subarrays are then sorted recursively and the, which is done in place which requires additional amounts of memory to perform sorting
- Its a comparison sort meaning it can sort anything a less than relation is defined
